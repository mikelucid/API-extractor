# Thoughtmon — creativity + training

Incomplete thoughts become creatures. Catch them, train them, evolve them.

## Loop

1. **Park / complete** unfinished thoughts (always finish)
2. **Catch** each finished seed as a Thoughtmon
3. **Train** at gyms: atelier (creativity), observatory (math), drill-yard, gatehouse, wilds
4. **Spar** with Gaussian \(R\) scores — creative duel, not combat sim
5. **Evolve** into Rasterdra when level ≥ 5 and cre/sharp ≥ 70

## CLI

```bash
npm run cli -- encounter muse
npm run cli -- dex
npm run cli -- train <id|nick> --gym atelier
npm run cli -- train-party
npm run cli -- spar <a> <b>
```

`complete` auto-catches finished thoughts into the party/box.
